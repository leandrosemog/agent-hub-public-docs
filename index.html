Agent Hub M5

Assistente privado para as próprias contas Gmail

O Agent Hub M5 é um assistente de uso privado administrado por Leandro Castro para interagir com suas próprias contas Google, pessoal e empresarial. Não é um serviço aberto ao cadastro de terceiros.

O que a integração faz

A integração permite atender pedidos do responsável sobre Gmail: consultar informações, organizar mensagens e marcadores, preparar respostas e enviar emails quando houver uma instrução aplicável. A conta é selecionada explicitamente em cada operação. As permissões técnicas não são uma ordem irrestrita para executar todas as ações disponíveis.

O acesso autorizado usa os escopos gmail.readonly, gmail.send e gmail.modify, além da identificação básica da conta Google. Não são solicitados outros serviços Google, os escopos gmail.settings ou o escopo mail.google.com, que inclui exclusão permanente. Os testes documentados não enviaram nem alteraram emails.

Como os dados são tratados

O responsável conversa com o assistente pelo WhatsApp, operado pela Meta. Conforme o pedido, dados selecionados do Gmail podem ser processados pelo modelo OpenAI usado pelo assistente e aparecer na resposta do WhatsApp. As credenciais operacionais são guardadas localmente em cofre do sistema operacional. Históricos e registros operacionais podem ser mantidos; não há promessa de retenção zero ou processamento exclusivamente local.

As regras do aplicativo limitam o uso de dados Google às funções solicitadas pelo responsável e proíbem venda, publicidade e uso para criar, treinar ou melhorar modelos gerais de inteligência artificial. O encaminhamento a fornecedores deve ocorrer somente em configurações compatíveis com essas regras. Isso não é uma afirmação de auditoria ou de configuração verificada de cada fornecedor.
